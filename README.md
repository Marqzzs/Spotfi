# 🎵 Spotfi

Projeto em **Java** desenvolvido para **consolidar conhecimentos de Programação Orientada a Objetos (POO)**, praticando a criação de classes com métodos, getters e setters e a aplicação dos pilares do paradigma.

---

## 📌 Sobre o projeto

O Spotfi é inspirado em uma plataforma de streaming de áudio. A proposta é modelar, por meio de classes e objetos, elementos como músicas, podcasts e uma lista de favoritos, com foco em organizar bem o código e praticar boas práticas de orientação a objetos.

## 🧠 Conceitos de POO praticados

- **Classes e objetos**: representação das entidades do sistema como classes
- **Métodos**: comportamentos de cada entidade
- **Encapsulamento**: atributos protegidos e acessados por **getters e setters**
- **Pilares da POO**: abstração, herança e polimorfismo aplicados na modelagem das classes

## 🗂️ Estrutura do projeto

```
Spotfi/
└── src/
    ├── Main.java
    └── br/com/alura/spotfi/
        ├── modelos/
        │   ├── Audio.java
        │   ├── Musica.java
        │   ├── Podcast.java
        │   └── MinhasPreferidas.java
        └── principal/
            └── Principal.java
```

| Pacote | Descrição |
|---|---|
| `modelos` | Classes que representam as entidades do domínio (`Audio`, `Musica`, `Podcast` e `MinhasPreferidas`) |
| `principal` | Classe responsável por executar e testar o programa |

## 🛠️ Tecnologias utilizadas

- Java (JDK 25 ou superior; o projeto está configurado com JDK 26)
- IntelliJ IDEA

## ▶️ Como executar

1. Clone o repositório:

   ```bash
   git clone https://github.com/Marqzzs/Spotfi.git
   ```

2. Abra a pasta do projeto no **IntelliJ IDEA**.

3. Confirme que o SDK do projeto é o JDK 25 ou superior.

4. Execute a classe principal do projeto.

## 📚 Aprendizados

- Como transformar entidades do mundo real em classes com atributos e comportamentos
- Uso de encapsulamento para proteger os dados e controlar o acesso a eles
- Organização do código em pacotes
- Aplicação dos pilares da POO na prática
